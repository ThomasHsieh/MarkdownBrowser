# App 圖示

深灰圓角方塊上一本翻開的書：象牙白內頁、暖橘書封，左頁是 Markdown 的 `M`、
右頁是向下箭頭，每頁下方兩道短線，其中一道是橘色。

顏色跟閱讀介面同一組：深灰是專注，紙白帶出文字的溫度，`#DD9853` 的橘是
「這裡值得停留」—— 也就是內文裡粗體的那個橘。符號只有 `M` 與箭頭，沒有字。

## 檔案

| 檔案 | 角色 |
|---|---|
| `AppIcon-v2.png` | **母圖**，1254 px。唯一的來源，要改圖示就換這一張 |
| `AppIcon-v2.prompt.txt` | 產生母圖用的提示詞，留著方便重做或微調 |
| `AppIcon.png` | 從母圖算出來的 1024 px 標準母版，供預覽 |
| `AppIcon.icns` | 實際打包進 `.app` 的圖示 |

`AppIcon.png` 與 `AppIcon.icns` 都是 `make icons` 產生的，不要手動改。

## make icons 在做什麼

兩件事，其餘交給系統工具：

**校正幾何，而且要滿版。** 母圖的圓角方塊只佔畫布 86.9%，先用 alpha 量出
方塊的實際範圍，再等比縮放成**填滿整個畫布**。

會滿版是因為 macOS 26：傳統的 macOS 圖示會在 1024 畫布裡留白（方塊 824 px，
四周 100 px 給陰影），但 macOS 26 的 Dock 會把這種舊格式圖示墊到系統自己的
底板上 —— 於是變成「板中板」，一塊淺灰底板中間放一個縮小的深色方塊，
比鄰居明顯小一圈。填滿畫布之後圓角與陰影交給系統的遮罩處理，
Dock 裡就跟其他 App 一樣大了。

（在 macOS 26 之前，留白版才是對的。這裡是照著實機 Dock 的樣子決定的。）

**縮圖用 Lanczos，不用 AppKit 的 `.high`。** 母圖是立體算圖，縮到 32–64 px
時 `.high` 內插明顯偏軟，在 LaunchBar 那種小圖清單裡看起來就糊。改用
CoreImage 的 `CILanczosScaleTransform`，64 px 以下再補一點 `CIUnsharpMask`
（強度 0.35 —— 再上去圓角方塊邊緣會浮出一圈黑色光暈，比糊還醜）。

**打包交給 `iconutil`。** 不要手刻 ICNS 容器：手刻版本會把 16／32 px 掛在
`icp4` / `icp5` 這兩個 OSType 上，而它們塞 PNG 是不可靠的 —— macOS 有解碼
路徑會當成原始點陣資料，解出來是一片彩色雜訊，偏偏大尺寸正常，很容易漏看。
