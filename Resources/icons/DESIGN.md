# App 圖示

深灰圓角方塊上一本翻開的書：象牙白內頁、暖橘書封，左頁是 Markdown 的 `M`、
右頁是向下箭頭，每頁下方兩道短線，其中一道是橘色。

顏色跟閱讀介面同一組：深灰是專注，紙白帶出文字的溫度，`#DD9853` 的橘是
「這裡值得停留」—— 也就是內文裡粗體的那個橘。符號只有 `M` 與箭頭，沒有字。

## 檔案

| 檔案 | 角色 |
|---|---|
| `AppIcon-v2.png` | **母圖**，1254 px。唯一的來源，要改圖示就換這一張 |
| `AppIcon-v2.prompt.txt` | 產生母圖用的提示詞，留著方便重做或微調 |
| `AppIcon.png` | 從母圖算出來的 1024 px 標準母版，供預覽 |
| `AppIcon.icns` | 實際打包進 `.app` 的圖示 |

`AppIcon.png` 與 `AppIcon.icns` 都是 `make icons` 產生的，不要手動改。

## make icons 在做什麼

兩件事，其餘交給系統工具：

**校正幾何。** 母圖的圓角方塊佔畫布 86.9%，而 macOS 的慣例是 1024 畫布裡
方塊約 824 px（80.5%），四周留白給陰影。照原樣打包會比 Dock 上其他圖示大一圈。
所以先用 alpha 量出方塊的實際範圍，再等比縮放、把**方塊的中心**對到畫布中心
（不是把整張母圖置中 —— 母圖的陰影不對稱，整張置中會讓方塊看起來偏上）。

小尺寸另計：16 與 32 px 用 14/16 的比例，留白比大尺寸少。Apple 自己的圖示
格線就是這樣，而這台機器是非 Retina 的 3840×1080，1× 素材真的會被用到，
多擠出來的那幾個像素在 16 px 下差很多。

**打包交給 `iconutil`。** 不要手刻 ICNS 容器：手刻版本會把 16／32 px 掛在
`icp4` / `icp5` 這兩個 OSType 上，而它們塞 PNG 是不可靠的 —— macOS 有解碼
路徑會當成原始點陣資料，解出來是一片彩色雜訊，偏偏大尺寸正常，很容易漏看。
