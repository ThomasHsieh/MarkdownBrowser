# Triage 標籤

skill 裡講的是五個標準的 triage 角色，這張表把角色對到這個 repo 的 issue tracker 實際用的標籤名稱。

| mattpocock/skills 的標籤 | 這個 repo 的標籤 | 意思 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等維護者評估 |
| `needs-info` | `needs-info` | 等回報者補資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可以交給 agent 自己做 |
| `ready-for-human` | `ready-for-human` | 需要人來實作 |
| `wontfix` | `wontfix` | 不會處理 |

skill 提到某個角色時（例如「標上可以交給 agent 的那個標籤」），用這張表右欄的名稱。

實際用的名稱不同時，改右欄就好。
